Mathematical Analysis

The derivative f'(x) determines the intervals where the function f(x) increases or decreases:

Increasing/Decreasing Test

(a) If f'(x) > 0 on an interval, then f is increasing on that interval.

(b) If f'(x) < 0 on an interval, then f is decreasing on that interval.

Intervals for f(x) = x³ - 2x

Critical Points: x = -√(2/3) ≈ -0.816, x = √(2/3) ≈ 0.816

Increasing: (-∞, -√(2/3)) ∪ (√(2/3), ∞)

Decreasing: (-√(2/3), √(2/3))

Proof of Concept:

For f(x) = x³ - 2x:

1. Find derivative: f'(x) = 3x² - 2

2. Solve f'(x) = 0: 3x² - 2 = 0 → x² = 2/3 → x = ±√(2/3)

3. Test intervals:

• For x < -√(2/3): f'(x) > 0 → Increasing

• For -√(2/3) < x < √(2/3): f'(x) < 0 → Decreasing

• For x > √(2/3): f'(x) > 0 → Increasing

Increasing Intervals

When f'(x) > 0, the function is increasing. Graphically, this means the function moves upward as we move from left to right. The slope of the tangent lines is positive.

Decreasing Intervals

When f'(x) < 0, the function is decreasing. Graphically, this means the function moves downward as we move from left to right. The slope of the tangent lines is negative.

Critical Points

Points where f'(x) = 0 or is undefined. These points mark transitions between increasing and decreasing intervals and are potential locations for local maxima or minima.
