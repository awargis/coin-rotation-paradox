Formal Definition

The number \( f(c) \) is a:

- local maximum value of \( f \) if \( f(c) \geq f(x) \) for all \( x \) in some open interval containing \( c \).

- local minimum value of \( f \) if \( f(c) \leq f(x) \) for all \( x \) in some open interval containing \( c \).

For function: \( f(x) = \frac{1}{3}x^3 - 2x^2 + 3x + 1 \)

First derivative: \( f'(x) = x^2 - 4x + 3 \)

Critical points when \( f'(x) = 0 \):

\( x^2 - 4x + 3 = 0 \) → \( (x-1)(x-3) = 0 \)

Critical points at \( x = 1 \) and \( x = 3 \)

Key Insights for JEE:

  • Local extrema occur at critical points where \( f'(c) = 0 \) or undefined
  • First derivative test: Sign change of \( f'(x) \) around \( c \) determines max/min
  • Second derivative test: \( f''(c) < 0 \) → local max, \( f''(c) > 0 \) → local min
  • Global extrema are the absolute highest/lowest points in the domain
  • The "near \( c \)" region is mathematically defined as an open interval around \( c \)
  • Always verify critical points using either test in JEE problems

JEE Pro-Tip: Advanced Problem Solving

For JEE problems, remember to check endpoints for absolute extrema in closed intervals. Practice visualizing functions to identify potential extrema quickly! When solving optimization problems:

  • Identify critical points by setting f'(x) = 0
  • Use the second derivative test for classification
  • Compare values at critical points and endpoints
  • Watch for points where derivative is undefined
