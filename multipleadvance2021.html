Set S₂: Constrained Pairs

S₂ = {(i, j) : 1 ≤ i < j + 2 ≤ 10, i, j ∈ {1, 2, ..., 10}}

This set contains pairs (i, j) where i is less than j+2 and j+2 is at most 10.

From j + 2 ≤ 10, we get j ≤ 8.

From i < j + 2, we get i ≤ j + 1.

Also, since i and j are at least 1, we have i ≥ 1.

So for each j from 1 to 8, the valid i values are from 1 to j+1.
