Mathematical Insights

Critical Points: Where derivative is zero or undefined

Global vs Local: Highest/lowest point in entire domain vs neighborhood

Local Maximum

A point where the function value is higher than all nearby points. The derivative changes from positive to negative. Mathematically, it's a point where f'(x) = 0 and f''(x) < 0. These represent peaks in the mathematical landscape.

Local Minimum

A point where the function value is lower than all nearby points. The derivative changes from negative to positive. Formally, f'(x) = 0 and f''(x) > 0. These are valleys where the function reaches its lowest point in a local region.

Non-Differentiable Points

Points where the derivative doesn't exist, such as sharp corners or discontinuities, can still be maxima or minima. Examples include |x| at x=0. These critical points require special analysis as standard derivative tests don't apply.
