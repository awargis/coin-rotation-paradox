Digit Sequence Problem

A cinematic explanation of combinatorial sequences with no consecutive zeros

Problem Statement

Let n denote the number of all n-digit positive integers formed by the digits 0, 1 or both such that no consecutive digits in them are 0. Let bn = the number of such n-digit integers ending with digit 1 and cn = the number of such n-digit integers ending with digit 0.

an

Total valid n-digit numbers with no consecutive zeros

bn

Numbers ending with digit 1

cn

Numbers ending with digit 0

2. Which of the following is correct?

a17 = b17 + c17
b17 = a16 + c16
b17 = b16 + c16
c17 = a16 + b16

Why?

The sequences follow the Fibonacci recurrence relation:

an = an-1 + an-2

bn = an-1

cn = an-2

This is because a valid n-digit sequence can be formed by appending '1' to any valid (n-1)-digit sequence, or by appending '0' to a valid (n-1)-digit sequence that ends with '1'.
