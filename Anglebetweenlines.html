About This Visualization

This interactive demo shows the angle between two lines using the formula:

tan θ = |(m₁ - m₂) / (1 + m₁m₂)|

Adjust the sliders to change the slopes and observe how the angle changes. Special cases like parallel and perpendicular lines are highlighted with visual effects.
