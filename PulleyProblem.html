Key Concepts

Critical Points: Where derivative is zero or undefined

First Derivative Test: Sign change indicates max/min

Second Derivative Test: Concavity determines max/min

Local Maximum

A point where the function value is higher than all nearby points. The derivative changes from positive to negative.

Local Minimum

A point where the function value is lower than all nearby points. The derivative changes from negative to positive.

Non-Differentiable Points

Points where the derivative doesn't exist, such as sharp corners or discontinuities, can still be maxima or minima.
