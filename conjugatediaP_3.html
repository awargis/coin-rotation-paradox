Ellipse Property: PS × PS′ = CD²

For any point P on ellipse: PS · PS' = CD²

Algebraic Proof

Step 1: PS² = a²(cosφ - e)² + b²sin²φ
Step 2: PS'² = a²(cosφ + e)² + b²sin²φ
Step 3: PS · PS' = √[PS² · PS'²]
Step 4: PS · PS' = a²sin²φ + b²cos²φ
Step 5: But CD² = a²sin²φ + b²cos²φ
∴ PS · PS' = CD²
