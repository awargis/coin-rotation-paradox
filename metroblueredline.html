Exploring Graph Theory Through Metro Station Connections

Let n > 2 be an integer. Suppose that there are n Metro stations in a city located along a circular path. Each pair of stations is connected by a straight track only. Further, each pair of nearest stations is connected by blue line, whereas all remaining pairs of stations are connected by red line. If the number of red lines is 99 times the number of blue lines, then what is the value of n?

Mathematical Solution

For n stations on a circle:

Number of blue lines = n

Total number of connections = C(n, 2) = n(n-1)/2

Number of red lines = Total connections - Blue lines

Red lines = n(n-1)/2 - n = n(n-3)/2

Given: Red lines = 99 × Blue lines

n(n-3)/2 = 99 × n

Divide both sides by n (since n > 0):

(n-3)/2 = 99

n - 3 = 198

n = 201

Answer: n = 201

When there are 201 stations, the number of red lines is exactly 99 times the number of blue lines.
