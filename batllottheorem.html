Ballot Theorem Explained

The Ballot Theorem solves an elegant problem in combinatorics: If candidate A receives m votes and candidate B receives n votes (with m > n), what is the probability that A is always ahead of B throughout the vote counting process?

Paths = (m - n)⁄(m + n) × (m + n)!⁄m!n!

Grid Representation

  • Each vote for candidate A is represented as a right move (→)
  • Each vote for candidate B is represented as an up move (↑)
  • The diagonal line y = x represents the condition where both candidates have equal votes
  • Paths must stay above the diagonal to ensure candidate A is always ahead

Pascal's Triangle Connection

Pascal's Triangle provides the binomial coefficients that count all possible paths without constraints. The Ballot Theorem provides a way to count only the paths that satisfy the diagonal constraint.

For 5 votes for A and 3 votes for B, Pascal's Triangle gives 56 total paths, while the Ballot Theorem calculates 14 valid paths.

Reflection Principle

The key insight is that any path that touches or crosses the diagonal can be reflected to create a one-to-one correspondence with paths from (-1,1) to (m,n). This allows us to calculate the number of invalid paths.
