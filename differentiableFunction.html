Mathematical Insight

Function Analysis

For f(x) = x² at x=0:
$$f'(x) = \lim_{h \to 0} \frac{f(x+h)-f(x)}{h}$$ $$f'(0) = \lim_{h \to 0} \frac{(0+h)^2 - 0^2}{h} = \lim_{h \to 0} h = 0$$ Function is differentiable.

Polynomial Characteristics

Roots & Zeros

The roots (or zeros) of a polynomial are the values of x for which the polynomial equals zero. These points represent where the graph intersects the x-axis. Polynomials of degree n can have up to n real roots.

$$ \text{For } P(x) = 0, \text{ roots } x_1, x_2, \dots, x_n $$

Differentiability

Polynomial functions are differentiable everywhere. This means they have well-defined derivatives at every point, and their graphs are smooth without any sharp corners or discontinuities. The derivative of a polynomial is another polynomial of one degree lower.

$$ \text{If } P(x) = a_nx^n + a_{n-1}x^{n-1} + \dots + a_0 $$ $$ \text{Then } P'(x) = na_nx^{n-1} + (n-1)a_{n-1}x^{n-2} + \dots + a_1 $$

End Behavior

The end behavior of a polynomial function depends on its leading term. For even-degree polynomials, both ends of the graph go in the same direction. For odd-degree polynomials, the ends go in opposite directions.

$$ \text{Degree even, leading coefficient positive: } \lim_{x\to\pm\infty} P(x) = \infty $$ $$ \text{Degree even, leading coefficient negative: } \lim_{x\to\pm\infty} P(x) = -\infty $$ $$ \text{Degree odd, leading coefficient positive: } \lim_{x\to\infty} P(x) = \infty, \lim_{x\to-\infty} P(x) = -\infty $$
